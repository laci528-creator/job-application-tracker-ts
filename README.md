# Job Application Tracker

A React + TypeScript project for tracking job applications and practicing modern frontend development.

## Technologies

- React
- TypeScript
- Vite
- CSS

## Current Features

- Display job application details
- Type-safe React components and props
- Manage job applications with React `useState`
- Add a sample job application
- Display the number of applications

## Getting Started

Clone the repository and install dependencies:

```bash
npm install
```

Start the Vite development server:

```bash
npm run dev
```

Build the project for production:

```bash
npm run build
```
